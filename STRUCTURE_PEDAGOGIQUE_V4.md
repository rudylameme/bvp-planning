# STRUCTURE PÉDAGOGIQUE V4 - À REPRODUIRE EN V5

## 🎯 Principe fondamental

La V4 suit un **cheminement logique en 3 temps** qui guide l'utilisateur :

```
1️⃣ JE ME COMPARE    →    2️⃣ JE REGARDE MA SITUATION    →    3️⃣ JE VOIS L'ENJEU
   "Où suis-je ?"              "Je progresse ?"                 "Qu'est-ce que je gagne ?"
```

**Objectif** : Lecture simple et rapide. L'utilisateur doit comprendre en 30 secondes.

---

## 🎨 Palette de couleurs harmonieuse (OBLIGATOIRE)

Utiliser cette palette cohérente dans tout le diagnostic :

| Élément | Couleur | Code Hex | Usage |
|---------|---------|----------|-------|
| **Moi / Actuel** | Bordeaux | `#8B1538` | Ma semaine, ma position, mes données |
| **Historique** | Gris | `#9CA3AF` | S-1, AS-1 (le passé = neutre) |
| **Secteur / Objectif** | Bleu | `#3B82F6` | Ce vers quoi je tends, la référence |
| **Potentiel / Gain** | Vert | `#22C55E` | Ce que je peux gagner, le positif |
| **Alerte / Perte** | Rouge | `#EF4444` | Problème, clients perdus |

**Règle visuelle simple :**
- Bordeaux = C'est **MOI**
- Gris = C'était **AVANT**
- Bleu = C'est la **CIBLE**
- Vert = C'est le **GAIN**

## 🧠 Résumé du fil conducteur

| Étape | Bloc | Question | Émotion |
|-------|------|----------|---------|
| **JE ME COMPARE** | 1-2 | "Je suis où ?" | Curiosité → Positionnement |
| **JE REGARDE** | 3-4-5 | "Je progresse ? Où je perds ?" | Fierté ou Alerte |
| **JE VOIS L'ENJEU** | 6-7 | "Combien je gagne ? Que faire ?" | Motivation → Action |
